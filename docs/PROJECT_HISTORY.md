## Decisions that remain in force

The project belongs to the user. GitHub stores code and safe examples; a runner executes jobs. GitHub-hosted machines support the demonstrated finite on-demand path; a personal PC/self-hosted runner is not required for it. n8n remains optional orchestration. A chat session, Codespace or Pages site is not an established continuous production host. No unlimited-free-service claim, API entitlement, future usage percentage or automatic transfer of personal connections was established.

TTS generates speech; faster-whisper recognizes it and estimates word timing. The working test uses Kokoro-ONNX CPU and faster-whisper CPU/int8. Kaggle/Kokoro notebook code exists but has not been executed on Kaggle here. Preserve known scripts/names and original recognition records. Do not regenerate saved narration just to edit pictures. A changed narration version invalidates an exact reviewed beat plan and needs realignment.

Prefer footage that depicts the narrated entity/action/location, with transparent reasoning and actual timing. Source quality and excessive portrait cropping caused earlier blurriness; retaining the source frame and selecting a better source are more useful than expecting sharpening to invent detail. The lightweight FFmpeg presets are not AI restoration or automatic quality judgment.

Channel names, registry slots, mocked OAuth tests and old chat authorization links do not prove live account access. No verified public post or active production scheduler resulted from this work. Source permissions and final human editorial/listening review remain distinct from technical validation. Future posting requires current supported authorization and provider reconciliation for uncertain results.
