# Optional operator labels

The [operator registry](../operators/registry.json) preserves seven interchangeable labels from the early handoff plan. They are documentation aliases, not login identities, social channels or running agents. Any authorized assistant can resume the project through the [same resume prompt](NEW_AGENT_PROMPT.md).

| Label | Optional focus | Prompt |
| --- | --- | --- |
| alpha | Coordination | [alpha](../prompts/alpha.md) |
| beta | Research and scripts | [beta](../prompts/beta.md) |
| delta | Shot planning | [delta](../prompts/delta.md) |
| epsilon | Voice and captions | [epsilon](../prompts/epsilon.md) |
| zeta | Rendering and quality | [zeta](../prompts/zeta.md) |
| eta | Reliability | [eta](../prompts/eta.md) |
| theta | Publishing and metrics | [theta](../prompts/theta.md) |

These labels do not require a seven-account rollout or delegation. See [continuity](CONTINUITY.md) for shared state and recovery.
