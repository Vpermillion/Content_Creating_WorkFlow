# Third-party components and sample provenance

- Sample visual assets are original SVG diagrams generated by `whatif/media.py`, explicitly marked illustrative and not to scale. No downloaded footage, music, sound effects or cloned voice is included.
- Local speech uses FFmpeg's libflite filter with the built-in CMU SLT voice. Debian's installed `/usr/share/doc/libflite1/copyright` was inspected on 2026-10-25. It contains permissive CMU/Edinburgh notices and additional notices for components/build files. Preserve applicable notices when redistributing the software; the runtime packages retain their package licenses. This is a prototype, not a voice-quality endorsement.
- Font rendering uses the distribution's DejaVu Sans package and its bundled license. Docker retains the installed package copyright information.
- FFmpeg is packaged by the host distribution or Debian worker image; enabled GPL components and codec rights depend on the distribution and use. No blanket license for third-party media is implied.
- The Kokoro software license was retrieved from `https://raw.githubusercontent.com/hexgrad/kokoro/main/LICENSE` on 2026-10-25 and preserved as `kokoro-license.txt`. This does not replace checking the weights/model card, built-in voices and target language at Kaggle execution time. No Kokoro weights are bundled.
- The official Kaggle kernel CLI reference is retained as a sourced operational reference; upstream URL and retrieval date are recorded in the Kaggle README.
- n8n is third-party software under its applicable license; the container is referenced, not relicensed by this project. The pinned image is reproducible, but image availability or the latest tag does not by itself establish a vulnerability assessment. Apply reviewed security updates before production exposure.
- NASA/NIH source URLs are reference candidates. Their contents were not retrieved through the blocked research route; facts remain provisional until verification. The demonstration narratives are original assistant-prepared text and distinguish scenario assumptions from claimed facts.

The uploaded master prompt is retained as the user-supplied specification, not as proof of current provider access, prices or policies.
